1. 실행과 화면 사용

ZIP 파일을 완전히 풀고 index.html을 Chrome 또는 Edge에서 엽니다. HTML만 다른 폴더로 옮기면 계산 코드와 그래프가 로드되지 않습니다. 일반 실행에는 Node.js, Python 또는 인터넷 연결이 필요하지 않습니다. 문헌 링크는 인터넷 연결이 필요합니다.

상단의 Text size에서 Compact, Standard, Large를 선택합니다. Compact 본문은 14 px입니다. 이 선택은 계산값에 영향을 주지 않습니다. 한국어 매뉴얼을 선택해도 프로그램의 입력·출력 명칭은 영어로 유지됩니다.

Analysis navigator의 단계 또는 Feature directory로 기능을 찾습니다. Interface view를 All workspaces로 바꾸면 전체 작업 탭을 볼 수 있습니다. 좁은 화면에서는 버튼이 아래로 이동하고 표는 표 내부에서 가로 스크롤됩니다. 긴 입력값은 입력창을 선택해 좌우로 이동하며 확인합니다.

2. 처음 계산하는 순서

  1. Project settings에서 물질, 국가·지역, 기준연도와 Model mode를 선택합니다.
  2. 유입량의 단위와 기간을 확인합니다. 예시로 1,000 kg을 입력했다면 실측 시장자료가 아니라 가정한 시나리오입니다.
  3. 제품별 배분, 사용 중 배출, 처리 공정과 EoL 비율을 확인합니다. 합계 오류는 Calculate 전에 수정합니다.
  4. 환경조건의 유량, 수용 면적, 혼합 깊이와 밀도를 확인합니다. 행정구역 전체 면적이 실제 수용 면적과 같다고 가정하지 마세요.
  5. Calculate를 실행합니다. 질량수지, 경고와 결과 단위를 먼저 읽습니다.
  6. 필요한 경우 Nanoform과 28-state fate를 켜고 다시 계산합니다.

기본 시나리오가 정상 실행되어도 현장에 적합한 입력값이라는 뜻은 아닙니다. 실제 자료로 교체한 항목과 가정으로 남긴 항목을 구분해 기록하세요.

3. 계산 모드와 질량수지

Static MFA는 선택한 기간의 flow 배분을 계산합니다. Dynamic MFA는 연도별 inflow, 제품 수명과 stock을 추적합니다. Probabilistic 계산은 지정한 불확실성 분포에서 입력을 반복 추출합니다.

기본 MFA의 PEC, 축약 4매체 fate의 PEC, 28상태 fate의 PEC는 서로 다른 계산 결과입니다. 논문과 표에는 사용한 모델을 함께 기록하세요.

기본 확인식은 초기 stock + 누적 inflow = 최종 stock + 누적 외부 outflow입니다. 내부 이동은 시스템 전체의 외부 손실로 다시 더하지 않습니다. 질량수지 100%는 장부상 보존을 뜻합니다. 현장 농도 정확도를 뜻하지 않습니다.

정상상태 fate는 모든 상태의 재고 변화와 유입·유출 잔차를 검사합니다. 지속 유입되는 상태에 외부 제거 경로가 없으면 정상상태가 성립하지 않습니다. 이때 반복 연수를 늘리는 것만으로 문제를 해결할 수 없습니다.

4. 형태와 질량 기준

28상태는 air, water, soil, sediment의 4매체와 7형태로 구성됩니다. 형태는 matrix-bound, free particle, small aggregate, large aggregate, dissolved, transformed particle, unresolved입니다. 이 구분은 운영상 정의이며 분석장비의 분획과 자동으로 일치하지 않습니다.

Parent-material equivalent는 원래 물질 기준의 환산 질량입니다. Element equivalent는 구성 원소 기준 질량입니다. 순수 ZnO의 경우 Zn 질량분율은 65.38/81.379입니다. 변환 후 생성된 황화물·피복체의 실제 총질량과는 다릅니다.

초기 stock은 현재 선택한 질량 기준으로 입력합니다. 기준 또는 원소 함량을 바꾸면 기존 초기 stock이 자동 환산됩니다. 같은 값을 다시 수동 환산하지 마세요. 외부 유입행의 tracking_basis는 그대로 보존되며 계산 시 변환됩니다.

혼합물·피복입자·조성이 불명확한 물질에는 확인한 원소와 질량분율을 입력해야 합니다. 추적 경계 밖 전환은 원소가 사라졌다는 뜻이 아닙니다.

5. 환경용량·반응속도·강우

수계 부피는 유량 Q와 체류시간의 곱으로 계산합니다. 기본 이류속도는 Q/V입니다. Soil과 sediment의 용량은 수용 면적 × 혼합 깊이 × 건조 벌크밀도입니다. 같은 질량이라도 용량이 작으면 PEC가 커집니다.

Physical rates는 직경, 밀도, 점도, 수심과 응집 조건을 알고 있을 때 사용합니다. 침강은 구형 입자의 Stokes 식에 기반합니다. 비구형 입자와 실제 응집체에 그대로 적용할 수 있다고 가정하지 마세요. 용해속도는 pH·리간드·포화도로부터 자동 예측되지 않습니다.

강우는 동적 모드에서 연말에 발생하는 이산 이동으로 처리합니다. 사건 직전 stock을 기준으로 각 이동량을 동시에 계산합니다. 그 사건에서 새로 퇴적물에 들어온 물질을 같은 사건으로 다시 재부유시키지 않습니다. 연도 목록이 비어 있으면 매 동적 연도에 적용합니다.

토양에서 중복 적용되는 이동 분율의 합은 100%를 넘을 수 없습니다. 강우는 정상상태 모드에서 사용할 수 없습니다. 연말 강우는 해당 연도의 연평균 농도에 소급 반영되지 않습니다.

6. 외부 자료와 연도 연결

외부 연결 CSV는 year, compartment, form, mass_kg_y, tracking_basis 열을 사용합니다. 물질과 domain_id도 현재 시나리오와 일치시킵니다. 프로그램에서 내보낸 CSV 형식을 먼저 확인하세요.

누락 연도는 기본적으로 오류입니다. 자료가 없는 연도를 실제 유입 0으로 취급하지 마세요. 유입이 0이었다는 근거가 있을 때만 zero-fill을 선택합니다. 한 줄의 연간 입력은 기본적으로 1년 동적 계산입니다.

Year end는 연말 stock에 해당하는 농도입니다. Annual mean은 연중 stock을 적분한 평균입니다. 두 값을 같은 관측자료와 혼용하지 마세요. 정상상태를 요청할 때는 일정한 연간 유입과 수렴을 확인합니다.

7. 계수의 출처와 적용 조건

Evidence and numerical qualification에서 Parameter evidence editor를 엽니다. 계수를 고른 뒤 Evidence type, Source, Material, Domain ID, Unit, 적용 연도·범위와 Conditions를 입력하고 Save parameter evidence를 누릅니다.

Measured는 측정값, Published proxy는 문헌에서 가져온 대리값, Calibrated는 자료에 맞춰 추정한 값입니다. 근거가 없으면 Screening assumption으로 남깁니다. 출처에는 DOI나 보고서명뿐 아니라 표·식·측정 조건도 기록하세요.

토양 면적의 내부 단위는 ha입니다. 속도 단위는 1/year입니다. 적용 범위와 단위가 맞지 않으면 감사표에 경고가 나타납니다. 출처가 등록됐다는 이유만으로 프로그램이 문헌의 진실성이나 현장 적합성을 인증하지는 않습니다.

Rate CV override는 해당 속도의 Monte Carlo 변동계수를 바꿉니다. Min/max는 적용 가능 범위의 기록이며 무작위 표본을 잘라내는 경계가 아닙니다.

8. 관측값 비교와 독립 검증

Observed concentration comparison에서 Template CSV를 받거나 행을 입력합니다. 물질, domain, model_source, medium, form, tracking_basis, statistic, year, observed, unit, role과 출처를 맞춥니다. 토양·퇴적물·슬러지 단위는 건조중량 기준이어야 합니다.

독립 검증 자격에는 dataset_id, analytical_method, sampling_period, background_treatment, measurand_scope, independence가 추가로 필요합니다. 보정에 사용한 dataset ID는 Calibration dataset IDs에 등록하세요. 같은 ID는 독립 검증 건수에서 제외됩니다.

연평균에는 full_year, 연말에는 year_end, 정상상태에는 steady_representative의 시간 대표성을 사용합니다. engineered_material과 independent 선택은 실제 근거가 있을 때만 사용하세요. 자연 배경이 섞인 총 금속농도는 공학적 나노물질 PEC와 자동으로 같아지지 않습니다.

Compare 후 일치한 행과 제외 이유를 읽습니다. RMSE와 bias는 같은 비교 지표끼리 해석합니다. 검출한계 미만 값은 임의로 절반값을 넣지 않고 통계에서 제외합니다. 메타데이터가 부족한 행은 진단 비교에는 남을 수 있지만 독립 검증으로 세지 않습니다.

9. 민감도와 불확실성

Run fate sensitivity는 속도와 환경용량을 각각 ±20% 바꾸고 PEC 변화를 계산합니다. 상류 MFA 배출량은 고정합니다. 값이 0인 계수는 비율 변화 대상에서 빠집니다. 결과는 국소 민감도이며 전역 민감도나 상호작용 분석이 아닙니다.

Kinetic-only는 속도만 바꿉니다. Linked는 지원되는 시나리오에서 유입량·공정·환경조건·형태 분율도 함께 바꿉니다. 외부 연결에서는 입력 형태 비율을 유지한 채 질량 규모를 바꿉니다. Stock-driven의 linked fate 계산은 지원되지 않습니다.

반복성은 Quick 50/100/200, Research 500/1000/2000, Extended 1000/2000/5000회로 확인합니다. 서로 다른 seed를 2–5개 입력합니다. 기준 10%는 사용자가 선택하는 수치 기준이며 현장 오차 허용치가 아닙니다.

P5–P95는 조건부 90% 모의 구간입니다. 현장자료로 보장한 예측구간이 아닙니다. 반복성 실패 시 표본 수, 입력 분포와 수렴 문제를 검토합니다. v2.5.0 시험 시나리오가 통과했다고 현재 시나리오도 자동 통과한 것은 아닙니다.

10. 저장·불러오기·문제 해결

Export scenario Excel은 입력 설정을 저장합니다. 결과 재현 패키지는 계산 결과와 근거·관측 비교·현재 진단을 함께 저장합니다. Export diagnostics Excel로 민감도와 반복성 진단을 따로 저장할 수 있습니다. 입력을 바꾼 뒤에는 다시 계산하세요.

Save in browser와 autosave는 현재 브라우저의 저장공간에 의존합니다. 브라우저 데이터 삭제나 다른 컴퓨터로 이동하면 보존되지 않을 수 있습니다. 장기 보관은 Excel 파일로 하세요.

문제확인할 내용
그래프가 비어 있음ZIP 전체를 풀었는지 확인하고 Calculate를 실행합니다. 결과 탭으로 이동한 후 창 크기를 바꿔 봅니다.
정상상태 미수렴지속 유입, 외부 제거 경로, 장기 잔류 상태를 확인합니다. 물리적으로 제거가 없으면 동적 결과를 사용합니다.
비교 자료가 제외됨매체·형태·질량 기준·연도·시간 통계·건조중량 단위와 제외 이유를 확인합니다.
글자가 잘림브라우저 확대를 100%로 맞추고 Text size를 확인합니다. 표는 내부 가로 스크롤을 사용합니다.

검증 범위:이 배포본의 실제 브라우저 그래프와 모바일 렌더링은 제작 환경의 로컬 파일 접근 차단으로 확인하지 못했습니다. 소스 및 이벤트 점검과 실제 화면 확인은 구분합니다. 계산 방법은 방법 문서, 실측 비교 한계는 공개자료 점검에서 확인하세요.
