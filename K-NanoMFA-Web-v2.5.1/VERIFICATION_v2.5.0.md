## 계산 검증

- `TEST_RESULTS_v2.5.0.json`: 회귀시험 **13개 파일 전부 통과**. 다중 물질·국가, 질량수지, 제품 수명, 형태 분할, 외부 연결, 관측값 비교를 포함한다.
- `REGRESSION_v2.5.0.json`: 이번 수정에 대한 **10개 신규 항목 통과**. 합성 관측 동일값 비교는 데이터 흐름 시험이며 현장 검증이 아니다.
- `SCIPY_VERIFICATION_v2.5.0.json`: 28상태 계산을 독립적인 SciPy 행렬지수와 비교했다. 속도 배율 0·1·10에서 최대 재고 차이 **7.72582×10⁻¹² kg**, 적분 재고 차이 **1.89204×10⁻¹² kg·year**. 이는 해당 선형식의 수치 정확도에 대한 근거이며 반응기작의 타당성 증명이 아니다.
- `DOM_TEST_RESULTS_v2.5.0.json`: 이벤트 초기화, 글꼴, 계산, 질량 기준, 입력 변경 후 재계산, CSV·Excel 왕복, 근거 보존 등 **18항목 통과**, 오류·알림 0건. Plotly는 대체 함수로 시험했다.

## Monte Carlo 반복성

`UNCERTAINTY_VERIFICATION_v2.5.0.json`의 합성 Ag 시나리오는 2025–2027년 각 매체에 연간 1 kg을 입력한다. 유입량·환경용량·속도를 연결 표본화했다. 실측 시나리오가 아니다.

- 표본 수: 500 / 1,000 / 2,000 / 5,000.
- seed: 73 / 173 / 273.
- 12개 실행, 총 **25,500회**. 각 실행을 별도로 계산했다.
- 네 매체의 P5/P50/P95에 대해 인접 표본 수 변화와 최대 표본 수의 seed 간 범위를 점검한 **120개 비교 모두 10% 이내**였다.
- 최대 변화 **7.4722%**: seed 73, 토양 P5, 1,000→2,000회.
- 이는 한 시나리오의 사전 선택한 수치 기준 통과다. 모든 물질·기간·정상상태·두꺼운 꼬리 분포의 수렴을 보장하지 않는다.

상관 구조 `(그룹 간, 그룹 내)`를 (0,0), (0.3,0.5), (0.8,0.9)로 바꿔 각각 2,000회, 총 **6,000회** 추가 계산했다. 수중 P95는 각각 0.000678328, 0.000681119, 0.000678812 µg/L였다. 이번 사례에서 차이가 작다고 해서 실제 상관 구조를 확인한 것은 아니다. 모든 매체 결과는 JSON에 보존했다.

전체 제품 MFA→nanoform→fate 연결 경로도 `verify_linked_v250.js`로 별도 **1,000회 실행하여 전부 완료**했다. 질량수지 분위수는 100%에서 허용오차 10⁻⁶ percentage point 이내였다. 결과와 설정은 `LINKED_VERIFICATION_v2.5.0.json`에 보존한다.

## 미확인 또는 제한된 사항

1. **독립적인 현장 PEC 검증은 완료되지 않았다.** 공개 Ag WWTP 자료는 집계 범위이며 추적 입자 등가량과 총 Ag의 정합성도 제한된다. [자료 점검 보고서](EMPIRICAL_CHECK_v2.5.0.md)를 참조한다.
2. **실제 브라우저 시각 검증은 완료되지 않았다.** 연결된 브라우저의 로컬 파일 접근이 보안 정책으로 차단되어 그래프 렌더링, 모바일 표시, 실제 다운로드 클릭을 확인하지 못했다. JSDOM 통과를 브라우저 통과로 표시하지 않았다.
3. **특정 지역의 실제 수문·토양·퇴적물 용량을 확보하지 못했다.** 임의 측정값을 만들지 않았으며 입력·출처 관리 기능을 제공한다.
4. pH·리간드·포화도에 따른 화학종 평형, 입경 분포의 population balance, 공간 유동 및 근접 배출원 구배는 여전히 미해석이다. 이를 필요로 하는 연구에는 모델 구조를 확장해야 한다.
5. 역추정으로 보정한 매개변수의 식별성 분석, 전역 Sobol 지수, 모델 구조 간 비교 및 현장 예측구간의 coverage 평가는 이번 결과에 포함하지 않는다.

**v2.5.0의 의미:** 알려진 계산·정합성 결함을 수정하고 검증 근거를 추적할 수 있게 개선했다. 모든 PEC가 실제 환경농도를 정확히 재현한다고 인증한 버전은 아니다.
